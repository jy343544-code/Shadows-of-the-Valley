# SHADOWS OF THE VALLEY
**An original Egyptian dark-fantasy action adventure for Android.**

This repository is a Unity starter codebase. It is not yet a complete Unity project or APK.

## Project target
- Engine: Unity 6 (URP recommended)
- Platform: Android
- Target devices: mid-range phones with 4–6 GB RAM
- Mode: single-player, offline
- Camera: third-person
- First milestone: a 10–15 minute playable combat prototype

## Current repository contents
- Player movement using CharacterController
- Third-person follow/orbit camera
- Basic melee hit detection
- Enemy health component
- Mobile virtual joystick and touch camera area
- Design and setup documentation

## Important
Unity Editor and Android Build Support require a desktop or suitable cloud workstation. Android phones can be used to manage this repository and edit files, but cannot run the standard Unity Editor workflow locally.

## Start here
1. Read [Unity setup](docs/UNITY_SETUP.md).
2. Read [Game design](docs/GAME_DESIGN.md).
3. Import the `Assets` folder into a new Unity 6 URP project.
4. Follow the prototype scene instructions in the setup guide.
