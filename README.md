# SHADOWS OF THE VALLEY
**An original Egyptian dark-fantasy 3D action adventure for Android.**

This repository is an evolving Unity 6 gameplay prototype, not yet a complete Unity project or APK.

## Target
- Unity 6 with Universal Render Pipeline (URP)
- Android, single-player, offline
- Third-person action combat
- Initial target: mid-range Android phones (4–6 GB RAM)
- First milestone: a polished 10–15 minute vertical slice

## Gameplay systems in the starter code
- Camera-relative third-person movement
- Mobile virtual joystick and touch camera input
- Three-step melee combo and enemy knockback
- Enemy health and basic chaser AI
- Shadow Tether for pulling enemies
- Jump and directional dodge
- Aerial launcher, four-hit air combo chain, and ground slam

## Visual direction
A cinematic, stylized-realistic ancient Egyptian dark-fantasy world: weathered sandstone, monumental ruins, volumetric dust, dramatic sun shafts, deep shadows, turquoise supernatural energy, detailed creatures, PBR materials, and responsive combat animation. Visual quality must scale to the Android device.

## Important build note
The standard Unity Editor and Android Build Support require Windows, macOS, or Linux (or a suitable cloud workstation). Android phones can manage this repository and edit files, but cannot run the standard Unity Editor workflow locally.

## Start
1. Read [Unity setup](docs/UNITY_SETUP.md).
2. Read [Game design](docs/GAME_DESIGN.md).
3. Import `Assets` into a Unity 6 URP project.
4. Follow the setup guide to assemble the greybox scene and connect mobile UI controls.
